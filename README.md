# SNHU-CS-360-Mobile-Architect-and-Programming
The mobile application that I developed is an Event Tracker App that is titled, "Evently". The goals of this app are to provide the user with a quick and easy way to manage and track their personal or professional events. The app consists of three different screens. The first screen is the "Login" screen. This is where the user can login to the app using a username and password, or create a new account. The second screen is the "Main" screen that displays a calendar and a list of events created by the user. This screen also includes a button to create a new event, and a button to delete an event. The last screen is the "Create Event" screen. This screen is where the user can create a new event and add it to the database. The designs of each of these screens is simplistic to prevent the user from feeling overwhelmed, while at the same time providing the user with all the features needed to meet the needs of the user. 
When developing the code, I used an Agile approach. I worked on the project in increments, and broke down the bigger portions of the project into smaller, more manageable pieces. This allowed me to ensure the coding logic was sound and free of errors. This will be the approach that I take on all future projects. To test the app to ensure it was functional, I uploaded the app to an Android emulator, and personally ran the app and tested all functions. This is important to allow me to ensure all the features work properly, and also allows me to test for outlier conditions that could possibly introduce an error, like an incorrect input type. During the development lifecycle, there were multiple points where innovation was required. For example, when creating the design of each screen, I made design decisions that I had to change later as the project progressed. The layout design of the main screen is where I am most proud of my abilities.
